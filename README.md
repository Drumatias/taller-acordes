# Taller de Acordes

Elige un acorde, escúchalo, guárdalo y repite para armar tu progresión, sin restricciones de tonalidad.
Inspirado en *Armonía Ilustrada* de Brian Callipari.

- `index.html` abre la versión para celular o para PC (recuerda la última que usaste).
- `pc.html` y `movil.html` comparten las progresiones guardadas.
- `sw.js` guarda la app para usarla sin internet.

## Actualizar
Reemplaza el archivo que cambió y sube a GitHub. Luego cambia `VERSION` en `sw.js`
(por ejemplo `taller-acordes-v2`) para que los teléfonos descarguen la versión nueva.
